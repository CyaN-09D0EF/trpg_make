# 지형·부족 생성 규칙 v0.2

새 세계는 **60 × 38, 2,280개 육각 타일**과 **4개 부족**으로 시작한다. 부족 수를 늘리는 대신 후보를 17종족으로 늘리고, 매번 그중 네 부족을 뽑는다. 후보 이름·초기 인구·서식 선호는 플레이테스트용 설정이다.

## 생성 순서와 재현

1. 시드로 대륙·수분·고도 분포를 만든다.
2. 육지·바다·호수와 기후별 지형을 구분한다.
3. 강·자원·유적을 배치한다.
4. 전체 후보를 무작위로 섞어 앞의 네 부족을 선택한다.
5. 종족 선호와 부족 간 거리를 고려해 시작 위치를 정한다.

지형, 부족 추첨, 부족 배치는 서로 다른 난수 흐름을 쓴다. **같은 생성 버전·시드·지도 크기에서는 지형, 네 부족과 그 순서, 위치가 모두 같다.** 시드를 비우면 새 시드를 발급한다. 이미 저장된 세계는 이 절차를 다시 실행하지 않는다. 이전 버전의 시드로 새 방을 만들면 이전 생성기와 결과가 다를 수 있으므로, 진행 중인 세계는 저장 기록으로 이어간다.

## 지형

| 항목 | 생성 기준 |
| --- | --- |
| 연결 | 동서 경계를 연결하는 원통형 지도. 남북은 연결하지 않음 |
| 대륙 | 동서로 이어지는 부드러운 대륙 분포에 작은 지형 변화를 합성 |
| 육지·수역 | 고도 분포가 낮은 순으로 전체 타일의 약 35%를 수역으로 지정. 나머지 약 65%는 육지 |
| 호수 | 연결된 수역 덩어리가 남북 끝에 닿지 않고 `max(3, 전체 타일 수 × 0.004의 내림)` 이하이면 호수. 기본 지도는 9타일 이하. 모든 시드에 호수가 생기지는 않음 |
| 해안·해양 | 호수 이외의 수역 중 육지에 직접 인접한 타일은 해안, 나머지는 해양. 큰 내륙 수역도 이 기준을 적용 |
| 기후 | 극 쪽은 설원·툰드라, 따뜻하고 건조한 곳은 사막, 나머지는 수분에 따라 초원·평원 |
| 고도 | 연속적인 고도 분포로 평지·언덕·산을 정함. 수역은 평지 |
| 식생 | 수분과 기후에 따라 숲·열대우림·습지. 사막 평지에는 드문 오아시스, 저위도 해안에는 드문 산호초 |
| 강 | 언덕·산에서 수원 후보를 섞어 `max(2, 전체 타일 수 ÷ 140의 내림)`개까지 선택. 인접 타일을 따라 가장 가까운 수역에 연결하며 합류 가능 |
| 범람원 | 강이 지나고 다른 특성이 없는 평원에 배치 |
| 자원 | 수역은 물고기, 숲은 사슴·목재, 구릉은 석재·구리, 온대 평지는 밀·과일·소 등을 추첨 |
| 자연 잔량·유적 | 수역의 육상 식물 잔량은 0. 사막·설원·산의 잔량은 적게 시작. 유적은 육지에서만 추첨 |

강 경계는 양쪽 타일에 동일하게 기록하고, 지도 밖으로 이어지는 강은 만들지 않는다. 강은 수역까지 연결되는 간략한 배수 경로다. 실제 고도에 따른 하향 흐름·침식·유량은 아직 계산하지 않는다. 자원과 유적은 모든 지형·시드에 반드시 존재하도록 보장하지 않는다.

## 시작 위치

- 본거지는 산·수역·설원을 제외한 육지에만 둔다. 모든 종족이 같은 정착지 제약을 따르므로 수생 종족도 물가의 육지에서 시작한다.
- 남북 가장자리를 피해서 인접 6타일이 있도록 하고, 그중 최소 3타일이 이동 가능한 육지인 곳을 고른다.
- 먼저 기존 본거지와의 최소 거리를 충족하는 후보를 찾는다. 기준은 `max(3, 지도 짧은 변 × 0.2의 내림)` 육각 거리이며 기본 지도에서는 7칸이다. 동서 경계 너머의 거리도 계산한다.
- 후보가 없으면 거리 기준을 한 칸씩 낮추되 3칸 미만으로 내리지 않는다. 그래도 네 부족을 둘 수 없으면 생성 오류를 알린다.
- 적격 후보 안에서 본거지와 주변 6타일의 종족 선호, 기존 본거지와의 거리, 작은 무작위 점수를 함께 평가한다. 선호는 가산점이며 특정 지형을 보장하는 강제 조건은 아니다.
- 선택한 위치에 본거지 표시만 붙인다. 시작 위치에 맞춰 바다를 메우거나 숲·강·자원을 덮어쓰지 않는다.

각 부족은 본거지 1개, 신도 0명, 노동 배치 0명, 기술·건물 없음으로 시작한다. 초기 식량은 해당 부족 월간 소비량의 **2.5개월분**(고기 1개월·곡물 1개월·과일 0.5개월)이며 소비량 0인 엔트의 식량도 0이다. 초기 주민의 연령은 기존 인구 시스템처럼 종족의 성숙 시점으로 해석한다.

신은 실제 생성된 네 부족 중 하나를 선택한다. 후보 목록 전체를 보는 것만으로 세계에 그 부족이 존재하거나 발견된 것으로 처리하지 않는다. GM 전체 지도, 신·신관의 개별 관찰, 선택 부족 외 세부 정보 제한은 기존 규칙을 따른다.

## 기존 세계

새 생성 규칙은 **새 세계 만들기**에 적용한다. 기존 세계와 불러온 기록의 부족·인구·시작 위치·지형을 추첨하거나 바꾸지 않는다. 새 세계 만들기의 **지형·부족 생성 규칙과 후보 목록**에서 규칙 요약과 17개 후보를 확인할 수 있다.
