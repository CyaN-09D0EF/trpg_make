# 3인 플레이테스트 운영 규칙

이 문서는 룰북 v0.4의 원문을 변경하지 않고, GM·신·신관 3인이 사용하는 첫 구현의 운영 방식과 임시 수치를 설명합니다.

## 역할과 정보

| 역할 | 주요 권한 | 관찰 범위 |
| --- | --- | --- |
| GM | 판정, 세계 서술, 시간 진행, 지형·자원·부족 수치 편집, 기술 기록, 자리 해제 | 전체 지도·캐릭터·비공개 기록 |
| 신 | 신 생성, 시작 부족 선택, 권능 제안, 대화, D100 | 시작 후보 부족 주변, 선택 부족 주변, GM이 공개한 지역 |
| 신관 | 부족 종족으로 캐릭터 생성, 인접 육상 탐험, 노동 배치, 행동 제안, 대화, D100 | 시작 정착지 주변, 직접 탐험한 지역, GM이 공개한 지역 |

GM은 별도의 세 번째 진행자입니다. 룰북의 두 플레이어 역할은 유지합니다. 플레이어가 발견한 지도는 다른 플레이어에게 자동 공유되지 않습니다. 현재 관찰 중인 정착지·신관 주변 외의 타일은 마지막 관찰 상태를 유지합니다. 타일 발견 시점이 오래되면 화면에 표시합니다.

전체 채팅 외에 수신 역할을 지정할 수 있습니다. GM은 진행을 위해 모든 비공개 메시지와 행동을 열람합니다. 행동 제안과 판정은 요청한 플레이어와 GM에게만 보이며, 정보 전달이 필요하면 대화나 계시로 명시합니다.

## 진행과 판정

1. GM의 방 생성 시 부족·인구·정착지·동물·자원이 먼저 생성됩니다.
2. 신은 신성 레벨 1·신앙 10·소영역 1개로 시작합니다. 부족 선택은 한 번만 가능하며 선택만으로 자동 개종하지 않습니다.
3. 신관의 종족은 선택 부족의 종족입니다. 힘·지능·사회성의 합계는 100이어야 합니다.
4. 신의 권능 및 신관의 자유 행동은 GM에게 제안합니다. GM이 실행 가능성과 신앙 비용을 판정합니다.
5. 승인된 신의 행동은 지정된 신앙을 한 번 차감합니다. 환경 변화와 발견은 GM이 별도 도구로 적용합니다. 예를 들어 곤충 기적을 승인한 후 식물 자원량을 줄이면 다음 월말 동물 이동의 서식 적합도에 반영됩니다. 비용은 GM이 실제 환경 변화의 규모로 판단합니다.
6. D100은 서버에서 생성합니다. 신성 보정은 서버에서 각 능력치에 `200 × n`을 더합니다. 불가능한 신체적 격차의 판정은 GM이 먼저 수행해야 합니다.
7. 일반 인접 육상 이동은 신관 화면에서 처리합니다. 이동 속도·시간·수역과 산 통과는 GM이 판정하고 시간을 진행합니다.

## 월말 정산

시험판에서 1개월은 30일입니다. GM이 시간·일·주·월 중 하나를 선택하여 시간을 진행하며, 월 경계를 넘을 때마다 해당 정산을 한 번씩 처리합니다. 자동 현실 시간은 사용하지 않습니다.

1. 정착지와 인접 6타일에서 노동자 수 × 생산량, 지형 생산 한도, 자연자원 잔량 중 가능한 만큼 생산합니다.
2. 겹치는 생산권은 타일별 생산 한도와 자연자원을 공유합니다. 현재 시험판은 생성된 부족의 순서로 배분하며, 공평 배분 알고리즘은 아직 없습니다.
3. 종족별 소비량 × 인구만큼 식량을 사용합니다. 소비 순서는 과일 → 고기 → 곡물이라는 시험판 편의 규칙입니다.
4. 식량 부족은 기록하지만 자동 사망·인구 감소는 적용하지 않습니다.
5. 선택 부족의 신도 수 × 0.5만큼 신앙을 더합니다. 감동 보너스·제단 효과는 GM이 별도로 판정하여 조정합니다.
6. 동물 개체군 일부가 인접한 적합 서식지로 이동합니다. 수역·육지는 분리하며 식물 자원, 강, 숲, 계절의 영향을 반영합니다. 실제 개체군 수를 원래 타일에서 빼고 도착 타일에 더합니다. 이어서 자연 회복과 시험용 수용 한도를 적용합니다. 포식자와 상세 종별 생태는 아직 모델링하지 않습니다.
7. 각 부족에 대해 서버 D100을 한 번 굴립니다. 시험 확률을 통과하면 사건 후보를 기록하며 효과는 GM이 결정합니다. 선택 부족 외의 사건·정산은 GM에게만 공개합니다.

목축, 제단 생산, 인구 자연 증감, 건축 자동화, 직업·스킬 경험치, 흉물·흉신 성장, 세부 전투, 신성 레벨 성장·봉신 회복은 미구현입니다. 시험 수치는 기존 확정 규칙으로 간주하지 않으며 실제 플레이 결과에 따라 조정합니다.
