# 신들의 문명 TRPG — 통합 룰북 v0.4

《슬기로운 문명생활》 기반 2인 협동 문명 육성 게임 · 2026년 10월 22일 기준

지금까지 정한 규칙을 하나로 정리했어. 이전에 확정한 규칙을 우선 적용하고, 웹게임 시험판을 만들면서 임시로 넣은 수치는 별도로 표시할게.

이번 정리에서는 특히 세계 생성, 신의 시작 부족 선택, 《문명 6》 기반 지형, 식량 생산, 동물 이동 규칙까지 반영했어.

## 제1장. 게임 기본 구조

### 1.1 게임 방식

게임은 신 플레이어 1명과 신관 플레이어 1명이 협동하는 문명 육성 TRPG다.

| 구분       | 신 플레이어                 | 신관 플레이어            |
| -------- | ---------------------- | ------------------ |
| 조종 대상    | 신                      | 신관 캐릭터             |
| 주요 활동    | 기적, 계시, 축복, 강신, 피조물 창조 | 탐험, 연구, 제작, 외교, 전투 |
| 성장 요소    | 신성 레벨, 신앙, 영역          | 능력치, 직업, 스킬        |
| 시작 부족 선택 | 담당                     | 선택된 부족의 구성원        |
| 정보       | 신이 관찰한 세계              | 신관이 알고 있는 세계       |

부족민, 야생동물, 다른 국가, 흉물 등은 세계에 독립적으로 존재하며 자율적으로 행동한다.

### 1.2 게임 시작 순서

1. 신 생성: 신 플레이어가 이름, 외형, 성향, 초기 소영역 하나를 정한다.
2. 세계 생성: 게임 시작 전에 지도, 지형, 자원, 야생동물, 부족, 인구, 정착지 등이 생성된다.
3. 시작 부족 선택: 신 플레이어가 이미 존재하는 부족 중 하나를 선택한다.
4. 신관 생성: 신관 플레이어가 선택된 부족의 종족으로 캐릭터를 만든다. 신관은 원래부터 해당 부족에 속한 인물이다.
5. 게임 시작: 두 플레이어가 각자의 시야와 권한으로 문명을 발전시킨다.

중요: 신관이 부족의 종족이나 인구를 임의로 설정하지 않는다. 부족의 특성은 세계 생성 단계에서 결정된다.

## 제2장. 신 시스템

### 2.1 초기 능력

신성 레벨

# 1

초기 신앙

# 10

초기 소영역

# 1개

신성 레벨과 신앙은 별도로 관리한다.

신성 레벨이 0이 되면 신상으로 봉인되는 봉신 상태가 되며, 이후 부활하거나 영구 소멸할 수 있다.

### 2.2 영역 체계

소영역

영역

대영역

고유영역

- 세계에는 7개의 대영역이 존재한다.
- 대영역은 도전을 통해 획득할 수 있다.
- 흉물과 흉신에게서 영역 카드 등을 얻을 수 있다.
- 신의 권능은 보유 영역에 따라 달라진다.

### 2.3 신의 권능

| 권능     | 기능                    |
| ------ | --------------------- |
| 기적     | 자연환경이나 현실에 직접적인 변화 발생 |
| 축복     | 생명체나 집단에 특별한 효과 부여    |
| 강신     | 대상에게 신성한 힘 부여         |
| 계시     | 신관이나 신도에게 정보 전달       |
| 피조물 창조 | 신의 힘을 가진 존재 생성        |

신의 권능에는 신앙이 소비되며, 정확한 비용은 권능의 종류와 규모에 따라 결정한다.

완성된 고급 기술을 인간에게 직접 주입하는 것은 막대한 신앙이 필요하지만, 작은 암시나 단서를 제공하는 것은 일반적인 기적으로 가능하다.

### 2.4 신앙 획득

월간 기본 신앙은 다음과 같다.

\\[ \text{월간 신앙}=\text{신도 수}\times0.5 \\]

매월 말 정산한다.

제단은 신도 수와 별도로 신앙을 생산하는 시설이며, 구체적인 생산량은 미정이다.

특별한 사건으로 신도들의 신앙심이 고취되면 추가 신앙을 얻을 수 있다.

| 신앙 고취 정도  | 1인당 보너스 |
| --------- | ------- |
| 작은 감동     | ×0.5    |
| 뚜렷한 감동    | ×1      |
| 강한 신앙 고취  | ×2      |
| 압도적인 기적   | ×5      |
| 역사적 신성 현현 | ×10 이상  |

보너스는 실제로 영향을 받은 신도 수를 기준으로 마스터가 판단한다. 자동으로 지급되는 것이 아니며, 동일 사건을 중복 계산하지 않는다.

## 제3장. 신관 캐릭터

### 3.1 기본 능력치

신관은 캐릭터 생성 시 100포인트를 배분한다.

| 능력치 | 설명            |
| --- | ------------- |
| 힘   | 신체 능력         |
| 지능  | 사고 및 학습 능력    |
| 사회성 | 의사소통 및 사회적 능력 |

일반 생명체의 기본 능력치 상한은 200이다.

### 3.2 특수 능력치

특수 능력치는 10종이다.

의지, 직관력, 음모, 통솔력, 매력, 창의력, 적응력, 집중력, 감응력, 관찰력.

모든 생명체는 각 특수 능력치를 잠재적으로 보유한다. 1 미만이면 정보창에 나타나지 않지만, 실제 판정에는 영향을 줄 수 있다.

### 3.3 직업과 스킬

- 한 캐릭터가 여러 직업을 가질 수 있다.
- 직업에는 레벨이 존재한다.
- 일반 스킬은 관련 행동을 통해 생성되고 경험치를 얻는다.
- 종족 특성은 별도의 경험치나 레벨 없이 항상 적용된다.
- 스킬의 경험치 요구량과 레벨 상한은 원작 확인 후 결정한다.

### 3.4 판정 규칙

기본 대립 판정은 D100을 사용한다.

\\[ P(A)=\frac{A}{A+B}\times100 \\]

단, 실제로 불가능한 신체적 격차는 단순한 주사위 운으로 극복할 수 없다.

신성 보정 `+Dn`은 능력치에 `200 × n`을 더한다.

예를 들어 힘 30(+D3)의 최종 힘은 630이다.

## 제4장. 세계 생성

### 4.1 육각형 세계 지도

세계는 시드 기반으로 무작위 생성한다.

| 항목     | 규칙                                 |
| ------ | ---------------------------------- |
| 지도 형태  | 육각형                                |
| 타일 한 변 | 2km                                |
| 타일 면적  | 약 10.4km²                          |
| 동서 방향  | 서로 연결되는 원통형 세계                     |
| 남북 방향  | 지도 경계 존재                           |
| 세계 구성  | 지형, 강, 기후, 자원, 동물, 부족, 정착지, 유적, 흉물 |

게임방 생성 시 세계의 기본 상태가 먼저 결정된다.

부족이나 동물은 플레이어가 발견하기 전에도 존재하며 활동한다.

### 4.2 플레이어별 시야

신과 신관은 서로 다른 시야를 가진다.

신은 피조물이나 영역 생물 등을 통해 정찰할 수 있고, 신관은 직접 탐험하거나 다른 인물에게 정보를 얻어야 한다.

한쪽이 발견한 정보가 다른 쪽에게 자동으로 전달되지는 않는다.

이미 발견한 지역이라도 장기간 관찰하지 않았다면 정보가 오래되었을 수 있다.

## 제6장. 자원

### 6.1 식량 자원

| 자원             | 활동    | 생산 식량 |
| -------------- | ----- | ----- |
| 사슴, 들소, 멧돼지    | 사냥    | 고기    |
| 물고기, 게         | 어업    | 고기    |
| 밀, 쌀, 옥수수      | 농경    | 곡물    |
| 야생 과일, 바나나, 포도 | 채집·재배 | 과일    |

식량 재고는 고기·곡물·과일 세 종류로 관리한다.

자원 아이콘이 없는 타일에서도 기본적인 사냥이나 채집이 가능할 수 있다. 자원 아이콘은 특정 자원이 풍부하다는 뜻이다.

### 6.2 기타 자원

목재, 석재, 점토, 구리, 철, 석탄, 말, 소, 양, 소금 등을 지도에 배치한다.

이 자원들은 건축, 제작, 교역, 군사, 목축 등에 활용한다.

## 제7장. 식량 생산과 소비

### 7.1 월간 식량 소비

| 소비 단계    | 1인당 월간 소비 |
| -------- | --------- |
| 적게       | 15        |
| 중간       | 30        |
| 많게       | 60        |
| 식량 소비 없음 | 0         |

종족별 현재 배정은 다음과 같다.

| 단계 | 종족                                       |
| -- | ---------------------------------------- |
| 적게 | 르나르, 코볼트                                 |
| 중간 | 인간, 리자드맨, 프로그맨, 놀, 엘프, 오크, 사티로스, 닉스, 드워프 |
| 많게 | 오우거, 트롤, 미노타우루스, 아스타시디안, 가루다             |
| 0  | 엔트                                       |

소비 단계별 수치는 확정이고, 종족별 배정은 임시안이다.

### 7.2 생산 활동

| 활동 | 생산·소비          |
| -- | -------------- |
| 사냥 | 고기 생산          |
| 채집 | 과일 생산          |
| 농경 | 곡물 생산          |
| 어업 | 고기 생산          |
| 목축 | 곡물을 소비하여 고기 생산 |

각 활동은 노동력과 시간을 필요로 한다.

### 7.3 생산권

정착지는 자신의 타일과 인접한 6개 타일, 총 7개 타일을 기본 생산권으로 이용한다.

서로 다른 정착지의 생산권이 겹치면 해당 타일의 자원을 공유한다.

### 7.4 지형별 생산 한도

각 타일에는 월간 생산 한도가 있다.

\\[ \text{실제 생산량} = \min(\text{노동력 기반 생산량},\text{타일 생산 한도}) \\]

이전에 제안한 기본 생산 한도는 다음과 같다.

단위: 식량/타일/월 · 시험용 수치, 미확정

| 지형  | 사냥 | 채집  | 농경  | 어업  |
| --- | -- | --- | --- | --- |
| 초원  | 80 | 100 | 150 | 0   |
| 평원  | 60 | 70  | 120 | 0   |
| 사막  | 10 | 5   | 0   | 0   |
| 툰드라 | 50 | 20  | 20  | 0   |
| 설원  | 20 | 0   | 0   | 0   |
| 해안  | 0  | 0   | 0   | 180 |
| 호수  | 0  | 0   | 0   | 200 |
| 해양  | 0  | 0   | 0   | 220 |

지형 특성 보정도 시험용으로 다음과 같이 제안된 상태다.

| 특성   | 사냥   | 채집   | 농경   | 어업   |
| ---- | ---- | ---- | ---- | ---- |
| 숲    | +100 | +80  | -50  | 0    |
| 열대우림 | +120 | +150 | -70  | 0    |
| 언덕   | +40  | -20  | -40  | 0    |
| 습지   | +40  | +80  | -60  | +80  |
| 범람원  | 0    | +30  | +150 | 0    |
| 오아시스 | 0    | +100 | +80  | 0    |
| 산호초  | 0    | 0    | 0    | +150 |

특정 자원이 있으면 생산 한도가 추가로 증가한다.

예를 들어 초원 + 숲 + 사슴인 타일은 시험 수치 기준으로 사냥 한도가 `80 + 100 + 100 = 280`이다.

### 7.5 자원 고갈과 회복

- 사냥, 채집, 어업은 자연자원을 감소시킨다.
- 자원은 환경에 따라 매월 일부 회복한다.
- 생산 한도와 현재 자원량은 별도로 관리한다.
- 농경은 토지 상태와 경작 시설의 영향을 받는다.
- 목축은 사료 공급량과 가축 수용 한도의 영향을 받는다.

자연 회복률과 노동자 1인당 생산량은 미정이다.

## 제8장. 야생동물 이동과 신의 유도

### 8.1 동물 자원의 이동

사슴, 들소, 멧돼지 등의 동물 자원은 지도에 고정된 물체가 아니라 이동 가능한 개체군이다.

이동에는 다음 요소가 영향을 준다.

- 먹이와 물의 분포
- 계절과 기후
- 포식자의 존재
- 주변 타일의 서식 적합도
- 신의 기적으로 변화한 환경

동물이 이동하면 기존 타일의 개체군은 감소하고 도착한 타일의 개체군은 증가한다.

### 8.2 신의 기적을 이용한 유도

신은 자신의 영역에 맞는 기적으로 자연환경을 변화시켜 동물의 이동을 유도할 수 있다.

예를 들어 곤충 영역을 가진 신이 곤충에게 특정 지역의 풀을 먹게 하면, 그곳에 살던 초식동물이 먹이를 찾아 다른 곳으로 이동할 수 있다.

이는 네뷸라가 곤충 영역으로 초식동물의 이동을 유도한 사례를 반영한 규칙이다.

환경을 조작해 이동을 유도하는 것과 동물을 직접 조종하는 것은 별개다.

기적 비용은 이동한 동물 수 자체가 아니라 신이 실제로 일으킨 환경 변화의 규모를 기준으로 계산한다.

이동 가능한 물고기나 곤충 자원에도 같은 원칙을 적용한다.

## 제9장. 정착지와 인구

### 9.1 인구 관리

부족 인구는 기본적으로 하나의 총인구 수치로 관리한다.

다종족 정착지는 식량 소비 계산을 위해 종족별 구성도 내부적으로 기록한다.

일반 NPC는 부족 단위로 처리하고, 신관과 주요 NPC만 개별적으로 관리한다.

### 9.2 정착지 단계

| 단계 | 종류  | 수용 인구 기준안       |
| -- | --- | --------------- |
| 0  | 야영지 | 10\~50명         |
| 1  | 촌락  | 50\~300명        |
| 2  | 마을  | 300\~1,000명     |
| 3  | 소도시 | 1,000\~5,000명   |
| 4  | 도시  | 5,000\~20,000명  |
| 5  | 대도시 | 20,000\~50,000명 |

이 인구 범위는 아직 최종 확정되지 않았다.

### 9.3 정착지 확장

인구가 증가하면 다음 두 가지 방식으로 성장한다.

- 건물 밀집도 증가: 기존 타일에 더 많은 건물이나 다층 건축물을 건설한다.
- 인접 타일 확장: 주변 육각형에 새로운 정착지를 세운다.

밀집도는 낮음, 보통, 높음, 초고밀도의 네 단계로 구분하는 방안이 제안되어 있다.

인접한 정착지는 도시권으로 연결할 수 있다.

주거지와 시설이 확장되면 기존 농경지나 자연 서식지가 감소할 수 있다.

발견

실험

## 제11장. 시간과 사건

### 11.1 시간 진행

| 상황      | 시간 단위  |
| ------- | ------ |
| 평화로운 일상 | 1개월    |
| 사건 대응   | 1주일    |
| 중요한 사건  | 1일     |
| 긴급 상황   | 1시간 이하 |
| 전투      | 전투 라운드 |

시간 단위는 문명 시대가 아니라 상황에 따라 변경한다.

장기 작업은 실제 경과 시간과 투입된 노동력에 따라 진행한다.

### 11.2 월간 사건

각 부족은 매월 D100으로 사건 발생 판정을 한 번 수행한다.

사건이 발생하면 해당 부족의 환경과 기술 수준에 맞는 카드 중 하나를 선택한다.

사건은 발견, 풍요, 재해, 질병, 사회, 외교, 군사, 신성 등으로 분류한다.

플레이어의 행동 때문에 발생한 사건은 월간 무작위 사건과 별도로 처리한다.

## 제12장. 흉물과 흉신

흉물과 흉신은 세계에서 독자적으로 성장하거나 영역을 차지하는 위험한 존재다.

부족이나 국가를 공격할 수 있으며, 처치하면 영역 카드나 정수 등을 획득할 수 있다.

전투와 보상 수치는 아직 미정이다.

## 제14장. 미확정 규칙 목록

앞으로 결정해야 할 항목을 모아두었어.

| 우선순위 | 항목    | 필요한 결정            |
| ---- | ----- | ----------------- |
| 높음   | 노동력   | 노동자 1인당 월간 생산량    |
| 높음   | 생산 한도 | 지형별 수치 최종 조정      |
| 높음   | 자원 회복 | 동물·식물·어류 회복률      |
| 높음   | 인구    | 출생률, 사망률, 종족별 증가율 |
| 높음   | 목축    | 곡물 → 고기 전환 비율     |
| 높음   | 기적    | 권능별 신앙 비용         |
| 중간   | 건축    | 건물 종류, 자재, 건설 시간  |
| 중간   | 기술    | 연구 조건과 진행량        |
| 중간   | 종족    | 종족 카드의 세부 수치      |
| 중간   | 사건    | 월간 발생 확률과 카드 효과   |
| 중간   | 이동    | 육상·해상 이동 속도       |
| 중간   | 외교    | 교역, 동맹, 복속, 전쟁    |
| 중간   | 전투    | 피해량, 방어, 부상       |
| 낮음   | 신관 계승 | 사망 후 캐릭터 계승       |
| 낮음   | 신성 성장 | 레벨 상승과 봉신 회복      |

현재 가장 중요한 부분은 생산량과 인구 소비량의 균형이야. 중간 소비 종족 100명이 한 달을 살아가려면 식량 3,000이 필요하지만, 앞서 제안한 지형별 생산 한도만으로는 초반 부족의 생존이 지나치게 어려워질 수 있어.

따라서 다음 작업에서는 이미 확정한 월간 소비량 15·30·60을 유지하면서, 지형별 생산 한도와 노동자 생산량을 그에 맞게 조정하는 것이 좋겠어.

이 문서를 현재 게임 규칙의 기준본으로 삼고, 이후 수정되는 항목만 갱신하면 돼.
